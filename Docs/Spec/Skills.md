# Skills

Skills guide the assistant through multi-step modding tasks: creating a block, adding a function to it, giving it a place on a G-Screen, overriding a definition. One skill per feature, so a modder's task combines several.

- The assistant works a skill's plan one item at a time and finishes by showing the result in the Editor (`Board.md`).
- It asks the modder for their choices (names players see, folders, values) and for steps the modder does in the Editor, and waits for them.
- A new thing gets its own name and text from the modder, even when a similar one exists.
- Skills ship with Veronica. The modder may edit them and add their own in the install folder; changes apply after clearing the chat.
- Edited skills survive updates (`Launcher.md`).

## Out of scope

- Work outside the Editor: importing models, art and audio, testing in game.
